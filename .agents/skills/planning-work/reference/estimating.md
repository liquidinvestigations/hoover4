# Optional estimation evidence

Estimate scheduled work in passes and state uncertainty.
Group work that shares dependencies, context, and verification.
Use measured outcomes when the tasks and harness are comparable.

Historical call counts and prices describe their sample.
They do not impose a task quota, role allocation, context fraction, or default budget.
A pass can contain the work needed for one coherent outcome.
Select its role from the actual risk and the configured harness mapping.

A useful estimate table contains the assignment, role, estimated passes, uncertainty, and eventual actual passes.
Money and duration estimates are optional when the person needs them and the measurements support them.
Do not add a separate verification allowance to a measurement that already includes verification.

The local analysis helpers remain available for an explicitly requested estimate study.
`mine-harnesses.py`, `mine-report.py`, `mine-cost.py`, and `mine-derive.py` inspect recorded sessions.
`pass-actuals.py` reads a completed transcript. `prices.py` supplies the recorded price inputs.
Verify sample coverage and current price inputs before drawing a new financial conclusion.
