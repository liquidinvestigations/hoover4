# Work package template

Use the fields needed to implement and verify the assignment. Link shared information.

## Assignment

Name the role, outcome, owned paths, baseline revision, and report destination.
State which decisions are settled and which actions are authorized.

## Design

Describe the affected interfaces, behavior, dependencies, and failure cases.
Link the shared technical design when one exists.
Give enough detail to avoid repeating research.

## Acceptance

Name runnable checks and their expected outcomes.
Identify commands or fixtures that the implementation must create.
State compatibility requirements and any prerequisite that blocks the work.

## Completion

Report changed behavior, checks with evidence, remaining requirements, and the next action.
Record an actual budget only when the person set one.
Do not add unrelated cleanup or expand the requested outcome.
