# Delegated work package

Use the shared [planning template](../../planning-work/reference/prompt-template.md).
Add the shared-checkout ownership and communication details needed by this agent.

Name the role, owned paths, required outcome, relevant decisions, checks, and report destination.
State any explicit budget and external-action authorization.
A routine continuation can update the existing assignment.

Wait for the agent and inspect its diff and evidence.
A report alone does not establish completion.
