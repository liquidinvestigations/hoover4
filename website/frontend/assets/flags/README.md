# Language flags

These 21 files are the language flags of [circle-flags](https://github.com/HatScripts/circle-flags) at commit `379588b5da95482d6bbf10bd45644a35b0609ea6`, under the MIT license in [LICENSE.md](LICENSE.md).

The upstream `flags/language/<code>.svg` files are symbolic links to country flags. Each file here is the resolved country flag, so the folder contains plain SVG files.
