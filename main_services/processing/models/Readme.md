# Language identification model

The worker includes the unmodified fastText lid.176.ftz model from Facebook AI Research.
The model uses the Creative Commons Attribution-Share-Alike 3.0 licence.
The [fastText language identification page](https://fasttext.cc/docs/en/language-identification.html) describes its training sources and licence.
The training sources are Wikipedia, Tatoeba, and SETimes.
The [licence text](https://creativecommons.org/licenses/by-sa/3.0/legalcode) applies to the model.
The fasttext-predict package uses the MIT licence.

The model file has SHA-256 `8f3472cfe8738a7b6099e8e999c3cbfae0dcd15696aac7d7738a8039db603e83`.
Its compressed size is 938,013 bytes.
The worker loads the local file and makes no model download at runtime.
