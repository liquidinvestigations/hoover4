## F-ingest-03

Extract archive, PST, OST, MSG, mbox, and TNEF members as documents. Preserve distinct item and attachment paths. Select plain, HTML, RTF, legacy rich text, and readable signed MIME bodies. Keep an unreadable signed body as an attachment, index the headers and other parts, and record a partial failure. Store body alternatives as separate sources. Mail raw text keeps headers and decoded bodies without attachment payloads. Mail containers take the archive route. A binary mail container type that only the file name gives is ignored when `file` reads the content as text. Retain opaque signatures without a verification claim. Record partial mail extraction as an Error while retaining readable members. Preserve safe attachment names and distinguish duplicate names with part paths. Bound error samples and retain their total count.

## F-auth-08

Resolve a caller of `/api/agent/v1/` from `X-Hoover4-User`, refuse a request carrying a proxy identity header or a session cookie, and expose the site's read surface to a tool-calling agent as 23 typed routes over collections, search, documents, tables, folders and images. `images/document` and `images/capture` answer with image bytes and an etag, and the other routes answer with JSON. A document route reads one explicit character range within a text page, one page of hits, or one page of a kept PDF search result. `documents/pdf_search` searches the whole PDF when no kept result matches, and `documents/sources` with a query counts the hits of every source over the whole document, so those two reads grow with the document under the 30 s deadline.
